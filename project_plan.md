# TSP - Transportes Sánchez Polo

## 1. Project Description
Sitio web corporativo de TSP (Transportes Sánchez Polo), empresa de transporte de carga terrestre e internacional fundada en 1970. Opera en Colombia, Ecuador, Venezuela, Perú, Brasil, Chile, Uruguay, Paraguay, Argentina y Bolivia. El sitio tiene como objetivo generar confianza, presentar servicios logísticos y captar leads de nuevos clientes.

## 2. Page Structure
- `/` - Página principal (Hero + Servicios + Diferenciadores + Sectores + Stats + Certificaciones + Formulario de contacto)
- `/servicios` - Página de servicios detallada
- `/contacto` - Página de contacto completa
